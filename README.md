# PVPUltimata

A game where players can control blocks that move around. The blocks can fight each other in PvP, and best of three wins.

## Controls
The controls can be changed in the key binds settings.
# Default controls: 
Cube 1: CFB to move, V normal attack, 1234 skills
Cube 2: arrow keys to move, down normal attack, 7890 skills

## Collectibles: 
There are four types: healing, strength, weakness, and speed, labeled HEL, STR, WEK, AND SPD, respectively. 

## Skills:
Skill 1: Shoots 3 bullets, does 10 damage each, and heals 3% health from player.
Skill 2: Shoots 3 lines, deals 10 damage and paralyses opponent for 8 sec.
Skill 3: Decreases 30% health from opponent. 
Skill 4: Shoots 3 triangles, deals 50 damage each.
